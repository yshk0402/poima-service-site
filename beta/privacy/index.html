ポイマ 招待テストのプライバシーポリシー

文書版：beta-privacy-2026-11-17-v1

株式会社Field Xは、ポイマの招待テストで扱う情報を以下のとおり管理します。本番サービスで将来利用する機能の説明とは分け、対象や外部送信先を変更する場合は開始前に案内します。

1. 取得する情報と目的

情報 利用目的
招待先メール、Google／Appleの利用者ID、確認済みメール、認証結果 招待者の照合、ログイン、アカウント保護、重複登録の防止
生年月日、日本在住の申告、同意した文書の版・日時 18歳以上・対象地域の確認、同意内容の確認
自分で設定した表示名・プロフィール画像 アプリ内プロフィールの表示
テスト残高、予測の回答・口数・結果・受取、パック、ミッション、交換の状態・日時 機能の提供、再送の検知、反映漏れや不正の調査
問い合わせ本文、返信先、対象の受付番号、アプリ・OSの版等 本人確認、回答、不具合の調査
認証・API等のIPアドレス、通信時刻、エラー、安全管理の記録 通信・認証、不正アクセスの防止、障害調査
TestFlightで利用者が送るフィードバック、スクリーンショット、Appleが提供する診断情報 テスト結果と不具合の確認、改善

Googleの名前・写真をそのまま公開プロフィールへ反映しません。Appleの非公開メールを選択できます。本人確認に必要な際も、パスワードや認証コードを問い合わせ本文で求めません。スクリーンショットには、他の人の個人情報やギフトURLを含めないでください。

2. 外部サービスと送信

提供先 このテストで扱う情報・用途
Supabase 認証、会員・同意・テスト取引等のデータベース、API、プロフィール画像の保管。主なDBは東京リージョン
Google GoogleログインのID、確認済みメール、認証に必要な情報。Google自身による取得・管理には同社の方針も適用
Apple Appleログイン、TestFlightの招待・配布・フィードバック・診断。Apple自身による取得・管理には同社の方針も適用
株式会社ギフティ 無料テストギフトの発行・照会に必要な申請識別子と数量等。ログイン情報、氏名、メールをギフトAPIの発行項目として送らない
Google Cloud ギフトAPIとの通信を東京の固定IPから中継。TLS通信の内容を復号して保存しない
Google Workspace support@poima.appのメール送受信・保管。返信先、件名、問い合わせ本文、添付、対応履歴等を扱う
GitHub Pages サポートページの配信と安全管理に必要なIPアドレス等の通信情報を処理
Cloudflare Turnstile Web問い合わせフォームの迷惑投稿対策。IPアドレス、ブラウザー・TLS接続等の技術情報、対象サイトの識別情報を処理

ADWALLは模擬処理であり、成果計測用に利用者の情報をセレスや広告主へ送信しません。SMS認証はこのテストでは使いません。

Firebase Analytics・Crashlyticsは、今回の限定版では収集を停止します。広告識別子による追跡や広告配信も行いません。今後利用を開始する場合は、送信項目・目的・保存期間と停止方法を事前に案内します。Appleが提供するTestFlightの診断・フィードバックとは別のものです。

問い合わせの専用メールはsupport@poima.appです。Webフォームで入力した返信先・本文・受付番号は、回答と重複受付防止のためSupabaseに保存します。Cloudflareへ問い合わせ本文やメールアドレスを送信する項目は設けません。Turnstileの技術情報は、Cloudflareによる不正アクセスの検知と検知機能の改善にも使用されます。フォームを利用できない場合は、専用メールから問い合わせできます。

3. 海外での処理と安全管理

DBの主な保管場所が日本であっても、認証、運用支援、診断等で国外で処理される場合があります。Supabase、Google、Apple等の契約上の事業者・委託先と、選択した機能によって処理国は異なります。外国への委託等では必要な保護措置を確認し、同意を根拠とする提供が必要な場合は、国・制度・保護措置等を事前に説明します。保護措置等の情報提供は窓口から請求できます。

アクセス権限を職務に応じて限定し、管理者の多要素認証、暗号化通信、秘密情報の分離、操作記録などを用います。個人情報を販売しません。法令に基づく場合等を除き、必要な同意なく第三者へ提供しません。

4. 保存・削除

テストのデータは本番へコピーしません。告知した終了日の30日後に、不要な認証情報、プロフィール、招待情報、残高・予測・交換・ミッション等のテスト記録を、対象を限定して通常の稼働環境から削除します。テストの架空取引を、一律に7年間保存する扱いにはしません。

終了前でもアプリ内から退会・削除を申請できます。本人確認後、通常のプロフィールや認証情報は原則30日以内に削除します。未完了の交換・問い合わせ、具体的な紛争・事故、法令上必要な保存は、対象・理由・保持期間を限定し、定期的に必要性を確認します。理由がなくなった情報は削除します。

当社管理の通常のアクセス・安全管理ログは原則90日以内とし、不要なものから削除します。問い合わせ記録は通常、対応完了から3年を上限としますが、招待テストの不要な記録には上記の終了30日後の削除を優先します。個人を特定できない不具合の再現手順や集計値は残す場合があります。IDを置き換えただけで本人に結び付く記録は個人情報として扱います。

バックアップは通常の利用から隔離し、利用する保管先の世代保持と削除手順に従って順次削除します。復元する場合は削除対象を再び除きます。AppleのTestFlight、認証事業者等が自身のサービスで管理する情報は、それぞれの削除手段・保持方針に従います。全ての外部保管先で同日に削除が完了することを保証するものではありません。

5. 確認・訂正・削除と窓口

ご自身の情報の開示、訂正、削除、利用停止等を希望する場合は、アプリ内のお問い合わせまたは公開窓口へご連絡ください。本人確認を行ったうえで、法令に従って対応します。対応できない部分がある場合は理由を説明します。

運営者：株式会社Field X。専用メール：support@poima.app。サポートページ：https://poima.app/beta/support/ 。一次返信は土日祝を除く原則2営業日以内を目標とし、調査が続く場合は5営業日ごとを目安に進捗を連絡します。
